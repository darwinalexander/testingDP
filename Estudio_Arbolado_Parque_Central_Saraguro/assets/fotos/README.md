# Fotos por árbol

Coloca aquí las fotografías descargadas de ArboLEC con esta convención de nombres:

    <ID>_1.jpg   <ID>_2.jpg   <ID>_3.jpg

Ejemplos: A06_1.jpg, A06_2.jpg, A06_3.jpg, AV02_1.jpg ...

Formatos admitidos: .jpg .jpeg .png

Luego ejecuta:
    python3 generar_pdf.py && python3 generar_informe.py

y las fotos se insertarán automáticamente en las secciones 6 (cipreses) y 8
(registro fotográfico) del informe, reemplazando los espacios reservados.
